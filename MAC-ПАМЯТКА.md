# Памятка для Mac: как забрать обновления с Windows (10.10.2026)

Ветка `for-mac` = `main` (45f3c17) + этот файл. Читать здесь, мёржить `main`.

## Что забрать

```bash
git fetch origin
git checkout main
git pull origin main
# если есть свои незакоммиченные правки — сначала stash/commit, потом pull
```

## Что обязательно после пула

1. **Node ≥ 20.9**: `node --version`. Next 16 / React 19 ниже не встанут.
2. **`npm install`** — зависимости сменились: `next 16.4.0`, `react/react-dom 19.3.0`,
   `@types/react 19`. Без этого dev не стартует.
3. **`.env.local` не переносится гитом** (gitignored) — остаётся твой.
   Нового обязательного env нет (`NEXT_PUBLIC_YM_ID` опционален).
   Важно: дефолтного пароля в коде больше нет (`lib/db.ts` требует `DB_PASS`
   из env) — убедись, что он у тебя задан, иначе сайт упадёт с access denied.
4. Первый `npm run dev` сам дообновит `tsconfig.json` (jsx: react-jsx) — так и надо.
5. Порт dev здесь `:3100` (`npm run dev -- -p 3100`), БД `hkoop` на 127.0.0.1:3306.

## База данных: твою не трогаем

Твоя локальная БД (211 новостей и т.д.) остаётся как есть. Но учти:
- Пароли на Windows сменены (утекли в историю гита — старые мертвы).
  Твои локальные пароли НЕ менялись. Секреты передаём лично, никогда в гит.
- Рекомендую ужать права сайтового юзера до чтения (у нас уже так):
  `REVOKE ALL PRIVILEGES, GRANT OPTION FROM 'hkoop'@'localhost';`
  `GRANT SELECT ON hkoop.* TO 'hkoop'@'localhost'; FLUSH PRIVILEGES;`
  (для миграций — отдельная root-учётка).
- Твои `fix_*.sql`, `seed*.sql`, `scripts/gen-search-index.mjs` в гит
  не попали — закоммить их сам, это всё ещё только у тебя.

## Что нового в коде (кратко)

- Безопасность: `lib/url.ts` (`safeHref` + `safeImgSrc`) для всего из БД,
  `poweredByHeader: false`, soft-404 через `notFound()`, `/news/[id]` —
  `await params` (в 16-м обязательно, иначе 500).
- Consent по 152-ФЗ: `lib/consent.ts` (`POLICY_VERSION = 2026-10-10-v1`),
  баннер с «Отклонить», карта и Метрика только после согласия,
  «Настройки cookies» в футере, новый роут `/policy`.
- Форма: чекбокс с целями/оператором/политикой, дисклеймер демо, лимиты длины.
- Дизайн/a11y: skip-link, aria-expanded у бургера, CLS-тамбы 16/10,
  ховер формы, счётчики 2.2с easeOutExpo.
- Скиллы: добавлен `arena` (аудит им и делался, протокол в `.arena/`),
  граф `graphify-out/` в main без кэша, `AGENTS.md` в корне сгенерил сам Next 16.
- `gh-pages` пересобраны отсюда (маленький сид). Полный ре-экспорт
  с твоей БД — отдельной командой, скажи когда.

## Чего не делать

- Не коммитить пароли (ни в `db/`, ни в `docs/`, ни в примерах команд).
- Не править `gh-pages` руками — генерится из `out/`.
- Деплой на Pages — только по команде, как раньше.
