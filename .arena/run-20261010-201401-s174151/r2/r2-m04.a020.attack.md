Where: r1-m06.a019.solution.md, «Допущения» п.3 и M6: «подключением к БД НЕ проверялись (вне разрешённого объёма) … дана команда для владельца»
Problem: MISSING — пропущено прямое требование задачи. Where: r1-m06.a019.solution.md, H2: «Проверка (инспекция + команды для владельца): … `npm ls next` (ожидается `next@14.2.5`) и `npm audit --audit-level=high` (ожидаются записи … точные строки сверить с выводом перед обновлением)»
Problem: MISSING — половина требования. Задача требует для каждой находки «проверкой (инспекция кода или живой probe с командой и выводом)». Пользователь не может отличить реальную уязвимость контура от пересказа бюллетеня. Проверка, которую надо было приложить: фактический вывод `npm ls next` и `npm audit --audit-level=high`.
