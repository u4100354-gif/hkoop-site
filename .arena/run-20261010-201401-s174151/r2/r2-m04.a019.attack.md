ATTACK 2 [FATAL] Ложный результат пробы path-traversal: заявлен 404, фактически 200
Where: П5 «`GET /news/..%2F..` → 404 — чисто»
Problem: Живая проверка опровергает: `curl.exe -s -o NUL -w "%{http_code}" "http://localhost:3100/news/..%2F.."` → `200`, а не `404`. Тот же класс подтверждается соседней пробой `GET /news/%3Cscript%3E` → `200` с телом «Не найдено». То есть маршрут `[id]` глотает кривые id в soft-200, а отчёт выдаёт это за «404 — чисто». Проверка несёт ложный факт о поведении роутера, на который опирается вывод об «инъекциях в путях».
