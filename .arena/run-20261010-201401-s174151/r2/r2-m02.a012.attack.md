ATTACK 1 [FATAL] F2: redirects якобы «унаследуют дыру» CVE-2025-29927
Where: «`next.config.js:9-24` уже содержит redirects, которые унаследуют дыру при появлении middleware» (F2).
Problem: ложный механизм. CVE-2025-29927 срабатывает только при наличии middleware (обход через `x-middleware-subrequest`); redirects в `next.config.js:9-24` — это не middleware, уязвимой поверхности они не создают. В дереве нет `middleware.ts`/`route.ts` (сам отчёт это признаёт: «Своего middleware нет»), значит заголовок сейчас ничего не обходит. HIGH без пути эксплуатации завышен, а утверждение про «унаследуют» неверно фактически.

ATTACK 2 [MAJOR] F15 — severity INFO и «Фикс не требуется» ломают формат задания
Where: «### F15. INFO — Партнёрские ссылки и логотипы: рекламы и нарушений АП не видно» + «Фикс не требуется», засчитано в чеклисте как закрытие пунктов 18–19.
Problem: задание требует «каждая с severity (CRITICAL / HIGH / MEDIUM / LOW)» и «предлагаемым фиксом». INFO нет в таксономии, фикса нет — это не находка по ТЗ, а констатация отсутствия проблемы. Пункты «Реклама/маркировка» и «Авторские права» тем самым закрыты не находкой, а отказом от находки.

ATTACK 3 [MAJOR] F5: «избыточные права» заявлены по README без проверки БД
Where: «Место: `db/README.md:11`» + «Проверка (инспекция кода/документации, БД не менялась): зафиксированы полные права».
Problem: задание требует для каждой находки «проверкой (инспекция кода или живой probe с командой и выводом)». Команды и вывода нет (`SHOW GRANTS` не выполнялся, хотя это чтение). Строка README «все права на базу hkoop» — это декларация инструкции, а не состояние грантов; при этом `db/README.md:25` говорит, что «Сайт пока читает `data/*.json`», т.е. даже какая учётка реально используется в проде — не установлено. Факт компрометации «перезапись/удаление таблиц» не доказан.

ATTACK 4 [MAJOR] F9: MEDIUM-находка из того, что PDF не прочитался
Where: допущение «текст `public/docs/politika.pdf` машинно не извлекался (ридер вернул пусто)» + «### F9. MEDIUM — Локализация ПДн не подтверждена».
Problem: нет ни цитаты, ни вывода команды — только отсутствие доказательства, поданное как нарушение ч. 5 ст. 18 / ст. 12 152-ФЗ. Проверяемые факты указывают на отсутствие нарушения: БД — `127.0.0.1:3306` (localhost по определению в РФ), форма (`components/ConsultForm.tsx:4`) — только `preventDefault`, внешние сервисы — Яндекс (юрлицо РФ). Фикс «вписать в политику…» не действует без знания содержимого политики, которое сам автор не извлёк, — пользователь не может его применить без догадок.

ATTACK 5 [MAJOR] F4: фикс заведомо не закрывает прод и противоречит F8
Where: «Фикс (без поломок): `async headers()` для dev/SSR … + в `app/layout.tsx` meta-CSP» с `frame-src 'self' https://yandex.ru`, при признании «Pages не отдаёт кастомные заголовки; директива `frame-ancestors` в `<meta>` игнорируется».
Problem: контрпример — применив фикс буквально, прод на GitHub Pages остаётся встраиваемым в чужой iframe (кликджекинг не закрыт), а CSP с `frame-src https://yandex.ru` разрешает карту по умолчанию, что прямо противоречит F8 («iframe только после клика/согласия», `app/contacts/page.tsx:23`). Один фикс отчёта отменяет требование другого.
