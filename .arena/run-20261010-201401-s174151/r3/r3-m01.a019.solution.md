### M1. MEDIUM — Нет заголовков безопасности: CSP, X-Frame-Options, HSTS, Referrer-Policy

- Место: `next.config.js:1-27` (нет секции `headers()`); URL: `http://localhost:3100/` (и все страницы).
- Проверка (живая проба, полный вывод 10.10.2026): `curl.exe -sI http://localhost:3100/` → `HTTP/1.1 200 OK`, заголовки: `Vary`, `Cache-Control: no-store, must-revalidate`, `Content-Type: text/html; charset=utf-8`, `Date`. Отсутствуют: `Content-Security-Policy`, `X-Frame-Options`/`frame-ancestors`, `Strict-Transport-Security`, `Referrer-Policy`, `Permissions-Policy`, `X-Content-Type-Options`. Позитив: `X-Powered-By` отсутствует.
- Факт: сайт с PDF-iframe (`components/DocsFilter.tsx:56`) без `frame-ancestors` уязвим к clickjacking-обёртке; без CSP любой будущий инлайн-скрипт/скомпрометированная картинка из БД получает максимум возможностей.
- Фикс (без применения; исправленный — прежняя рекомендация про meta была частично неверна): 1) для dev/будущего серверного хостинга — `async headers()` в `next.config.js`: `Content-Security-Policy` (с allowlist `'self'`, `mc.yandex.ru`, `yandex.ru/map-widget`), `X-Frame-Options: SAMEORIGIN` (или `frame-ancestors 'self'`), `Strict-Transport-Security`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy: camera=(), microphone=(), geolocation=()`, `X-Content-Type-Options: nosniff`; 2) для статики на GitHub Pages, где `headers()` игнорируется и произвольных заголовков нет: в `app/layout.tsx` — только `<meta http-equiv="Content-Security-Policy" content="...">` (действует, но `frame-ancestors` в нём игнорируется по спецификации CSP) и `<meta name="referrer" content="strict-origin-when-cross-origin">` (именно `name`, не `http-equiv`); `X-Content-Type-Options` через meta не выставляется вообще — это только HTTP-заголовок; 3) честная оговорка: HSTS, `frame-ancestors` и `nosniff` средствами Pages не закрыть — при переезде на свой домен с HTTPS отдавать их на уровне хостинга/CDN, до тех пор остаточный риск зафиксировать. Проверка meta-фикса через `curl -sI` заголовков не даст (ожидаемо) — проверять по `curl -s ... | Select-String "Content-Security-Policy"`.
