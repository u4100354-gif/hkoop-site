ATTACK 6 [MAJOR] Фикс L2 ломает рабочие ссылки на старый сайт
Where: L2, Место `app/page.tsx:37`, Фикс: "прогнать `old_url` через тот же `safeHref`, иначе — `/docs`"
Problem: контрпример: `d={file_local:null, file_old:null, old_url:"/news/xyz"}` сегодня даёт рабочую `https://habprof.ru/news/xyz`, а `safeHref("/news/xyz")` возвращает `"/news/xyz"` (совпадает с `/[^/\\]`), т.е. по фиксу ссылка уведёт на несуществующий путь нового сайта → 404. Как написан, фикс либо ломает fallback, либо (с сохранением префикса) — no-op; применить без догадок нельзя.
