# Аудит сайта ХКООП: безопасность и соответствие законам РФ (включая 152-ФЗ)

Дата: 10.10.2026. Объект: рабочее дерево `hkoop-site` (ветка `backup-2026-10-10`, как есть), dev-сервер http://localhost:3100, phpMyAdmin http://127.0.0.1:8081. Проект не менялся: только чтение кода и безопасные GET-пробы. Секреты в отчёте не печатаются (только имена ключей).

## Допущения (что проверено, что принято как гипотеза)

1. `NEXT_PUBLIC_YM_ID` в dev-окружении не задана: в HTML главной скрипта Метрики нет (живая проба). Поведение при заданном счётчике оценено по коду `app/layout.tsx:27-31` — помечено «по коду».

3. Права mysql-пользователя подключением к БД НЕ проверялись (выходит за «только SELECT без чтения секретов» в рамках этого аудита) — честно помечено ниже как «не проверено», дана команда для владельца.
4. Данные о CVE — по открытым бюллетеням Next.js; перед применением фикса сверить выводом `npm audit` (команды даны в H2).

## Проверено — держится (ранее исправленное, перепроверено)

### M5. MEDIUM — Два `img src` из БД идут мимо allowlist (хранимый вектор при компрометации БД)
