# Аудит сайта ХКООП: безопасность и соответствие законам РФ (включая 152-ФЗ)

Аудит проведён по рабочему дереву (`backup-2026-10-10`, как есть, проект не менялся; БД — только чтение кода/сидов и безопасные GET; секреты не печатаются — только имена ключей `DB_HOST/DB_PORT/DB_USER/DB_PASS/DB_NAME`). Прочитаны `CONTEXT.md`, `AGENTS.md`, ключевые файлы из задачи. Прод — статический экспорт (`output: export`) на GitHub Pages; серверные поведения проверялись на `http://localhost:3100`.

### N5. MEDIUM — Iframe-превью документов принимает произвольный https (фишинг от имени сайта)
- **Место:** `components/DocsFilter.tsx:42,50-56` + `lib/url.ts:3-9`.
- **Проверка (инспекция):** цитата: `{safeHref(d.file_local) && <button ... onClick={() => setPreview(safeHref(d.file_local)!)}>Смотреть</button>}` → `{preview && (... <strong>Просмотр PDF</strong> ... <iframe src={preview} ... />)}`. `safeHref` проверяет только схему (`https?://` или `/[^/\\]`), домен не проверяет. Контрпример: `file_local=https://evil.example/phish.html` проходит фильтр и рендерится в iframe внутри доверенного chrome страницы с заголовком «Просмотр PDF». `javascript:`/`data:` режутся (хорошо), но это не спасает от https-фишинга.
- **Фикс:** allowlist префикса: принимать только site-relative `/docs/*.pdf` (плюс явно перечисленные домены при нужде), всё остальное — только ссылкой с пометкой внешнего ресурса, не iframe.

### N6. MEDIUM — Два сырых `src` из БД без safeHref: логотипы партнёров и фото книги почёта (трекинг-пиксель)
- **Место:** `components/PartnersStrip.tsx:11` — `<img src={p.logo} ... onError={...}>` (сырой; `safeHref` на строке 21 покрывает только `href`, не `src`); `app/honor/page.tsx:14` — `{h.photo ? <img src={h.photo} ... /> : ...}`.
- **Проверка (инспекция):** `safeHref` (`lib/url.ts:3-9`) режет `javascript:`/`data:` и длинные строки, но на оба `src` не вызывается. По сидам текущие значения — `/images/*` (чисто). Современные браузеры не исполняют `javascript:` в `<img>`, React экранирует разрыв атрибута — сегодня это не рабочий XSS, а privacy-дыра: строка с `logo=https://evil-tracker/1px.gif` отдаёт IP/Referer/User-Agent третьему лицу без согласия, а при будущих изменениях — мина.
- **Фикс:** `const src = safeHref(p.logo)` / `safeHref(h.photo)` с fallback-плейсхолдером (как уже сделано для битой картинки через `onError`), плюс allowlist доменов картинок при желании.

### N7. MEDIUM — Нет заголовков безопасности и CSP
- **Место:** `next.config.js` (нет секции `headers()`), `app/layout.tsx` (нет meta CSP).
- **Проверка (живая проба):** `curl.exe -sI http://localhost:3100/` → `HTTP/1.1 200 OK`, `Vary`, `Cache-Control: no-store, must-revalidate`, `Content-Type: text/html; charset=utf-8` — нет `Content-Security-Policy`, `X-Frame-Options`/`frame-ancestors`, `X-Content-Type-Options`, `Referrer-Policy`, `Strict-Transport-Security`, `Permissions-Policy`, нет `X-Powered-By` (хорошо, `poweredByHeader: false` в `next.config.js:5`).
- **Факт:** сайт встраиваем в чужой iframe (кликджекинг формы), MIME-sniffing не запрещён, сторонние загрузки не ограничены.
- **Фикс (с учётом статики):** `headers()` Next при `output: export` на GitHub Pages игнорируется (сервера нет), `<meta>` не задаёт `frame-ancestors/X-Frame-Options/nosniff/HSTS` — поэтому: (а) выставить заголовки на уровне хостинга (GitHub Pages заголовки не даёт — перенести прод на хостинг с заголовками либо положить сайт за reverse-proxy/CDN с ними: CSP `default-src 'self'; script-src 'self' https://mc.yandex.ru; frame-src https://yandex.ru; img-src 'self' data: https:; object-src 'none'; frame-ancestors 'self'`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy`); (б) в самом коде добавить `<meta http-equiv="Content-Security-Policy" ...>` как второй рубеж и JS frame-busting (`if (top !== self) ...`) для кликджекинга; (в) проверить, что Метрика/карта не ломаются.

## Проверено — нарушений нет (с доказательствами)

- **SQL-инъекции:** все вызовы `q()` — статические строки без конкатенации; единственный параметр — `WHERE id=?` (`app/news/[id]/page.tsx:17`). Пробы: `/news/1%27%20OR%20%271%27=%271` → 200 «Не найдено», `/news/999999` → 200 «Не найдено», 500/стектрейсов нет. Команда: `curl.exe -s http://localhost:3100/news/1%27%20OR%20%271%27=%271`.
- **Отражённый XSS (`?q=`):** `app/search/page.tsx` — клиентский фильтр, вывод через JSX (экранируется). Проба `/search?q=%3Cscript%3Ealert(1)%3C/script%3E` → 200, сырого `<script>alert` в теле нет, есть экранированное `&lt;script` в `value`.
- **Инъекции в путях:** `/news/..%2F..%2Fetc%2Fpasswd` → 200 «Не найдено», App Router мапит как `id`, SQL всё равно через `?`.
- **Секреты по HTTP / заголовки:** `/.env.local` → `404`; `X-Powered-By` отсутствует на всех проверенных URL (`poweredByHeader: false`, `next.config.js:5`); хардкода паролей в коде нет (`lib/db.ts` — только `process.env`); исключение — N1 (пароли в `db/README.md`, не `.env`).
- **API/мутации:** каталог `app/api` отсутствует, все `q()` — `SELECT`; форма — `preventDefault` без `fetch` (Network пуст).
- **Ошибки:** несуществующие id/кривые параметры дают штатное «Не найдено», 500/трейсов нет.
- **Импринт (ст. 10 149-ФЗ):** адрес, телефон, email есть в шапке (`Header.tsx:52-54`) и подвале (`Footer.tsx:6-10`).
- **Политика (152-ФЗ):** `public/docs/politika.pdf` существует и отдаётся `200 application/pdf` по `/docs/politika.pdf`; ссылка с `/docs` есть (но с формы и баннера ведёт не туда — см. N8/N9).
- **Партнёрские ссылки/реклама:** характер информационный (лого+название, `PartnersStrip`), признаков рекламы по 38-ФЗ нет; `safeHref` режет не-http(s) схемы (но не чужие https в iframe — см. N5).
- **Авторские права:** логотипы/фото — информационное использование организацией (ст. 1274 ГК РФ, оценка по открытым данным; чистоту по каждому логотипу подтвердить договорами).
- **phpMyAdmin:** только с логином (проба выше: `loginform`, `logged_in:false`).

## Замечания вне ранжирования (не находки безопасности)

- `rel="noreferrer"` без явного `noopener` (`PartnersStrip.tsx:29`, `DocsFilter.tsx:43`): по спецификации `noreferrer` подразумевает `noopener`; явный `rel="noopener noreferrer"` — гигиена для старых движков, правится одной строкой.
- `generateStaticParams` (`app/news/[id]/page.tsx:11-14`): `id` из БД может быть числом при типе params `string` — строгий `String(n.id)` уберёт warning сборки, на безопасность не влияет.
- Публичный `search-index.json`/`data/*.json` отдают контент поиску by design — не класть туда ничего, кроме заголовков/отрывков.

## Вердикт

Сайт показывать людям нельзя, пока не убраны пароли из db/README.md (смена паролей, gitignore) и не урезан GRANT; затем первым чинить уязвимый Next.js и согласие на Метрику/карту, далее заголовки хостинга, форму и iframe-allowlist.
