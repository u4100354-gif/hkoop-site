ATTACK 1 [FATAL] Фикс заголовков через next.config.js headers() не сработает в проде
Where: находка 5, фикс — «добавить в `next.config.js` секцию `async headers()`»; задача: «Прод — статический экспорт (Next `output: export`) на GitHub Pages»; код `next.config.js:1-7` (`isExport ? { output: "export", ... }`)
Problem: при `output: export` Next игнорирует `headers()` — нет сервера, отдающего заголовки. Контрпример: собрать `STATIC_EXPORT=1 npm run build` и залить на Pages — `headers()` ни на что не влияет, `frame-ancestors`/`nosniff` не появятся. Рабочий фикс для этого прода — meta-теги или конфиг хостинга, а не `headers()`. Дополнительно неверно «HSTS — только после перехода на HTTPS»: Pages уже отдаёт HTTPS.
