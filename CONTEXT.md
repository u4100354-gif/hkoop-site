## Что это

Новый сайт Союза «Хабаровское краевое объединение организаций профсоюзов» (ХКООП).
Старый habprof.ru (Joomla 3.10, EOL) не трогаем. Разработка локально, демо на GitHub Pages.

## Стек (после мержа for-mac, 12.10)

- Next.js 16 App Router + React 19 + TypeScript, `poweredByHeader: false`
- Шрифт Manrope через next/font (кириллица+латиница); VI-режим — Arial
- CSS без фреймворков (`app/globals.css`, токены в `:root`), Turbopack dev
- MariaDB, доступ через `lib/db.ts` (mysql2 pool, только SELECT у юзера сайта; миграции через root)
- Локально: http://localhost:3100 (dev), phpMyAdmin http://127.0.0.1:8081, БД `hkoop`
- Прод-слепок: https://u4100354-gif.github.io/ (статика из `.next-export`, деплой вручную из папки)
- Репозиторий `u4100354-gif/hkoop-site`, ветки: `main` (всё), `skills-only` (скиллы+правила+граф для переноса), корень `u4100354-gif.github.io:main` (голая статика)

## Стиль «Apple-сцены» (прописано 14.10, по итогам арены 10 агентов)

Страницы /activity и /partners строятся «сценами» в духе продуктовых страниц Apple:
- Полновысотные сцены: min-height clamp(620px, 92svh, 860px), контент по центру.
- **Жёсткие стыки цветовых плоскостей** — никаких блендингов/мостов-градиентов (пробовали,
  не читаются: бандiнг и «туман» перед светлой сценой). Между тёмными сценами —
  hairline 1px rgba(255,255,255,.09); тёмная→светлая — чистый резкий стык.
- Порядок контента сцены: номер → eyebrow (цвет-акцент сцены) → заголовок → **кнопки (CTA)**
  → текст (подробности) → чипы-факты. Стрелка в CTA — в собственном кружке (button-in-button).
- Без watermark-цифр на фоне (решение владельца 14.10: убраны — читаемость важнее).
- Фоны сцен (все одобрены владельцем, держаться за них):
  01 navy→тёмный (Правозащита, акцент красный #e05252, триколорная черта под eyebrow),
  02 винный→navy-хвост (Охрана труда, #ff9d9d), 03 индиго→золото (Соцпартнёрство, #f0c264),
  04 тёмный зелёный→лесной (Молодёжь, #9ae6b4), 05 «ночь на Амуре» navy-синий (Международное, #b8d4f0),
  06 белый→крем (Организационная, янтарь #8a6a12). Красный разрешён (флаг/НДН).
- Боковой навигатор-точки: fixed right 40px (не прижимать к краю), мишень 24px,
  активная точка в цвете сцены, подпись ТОЛЬКО на hover/focus-visible (иначе перекрывает текст).
- Reveal при прокрутке: stagger-сборка (номер→надпись→заголовок→кнопки→текст→чипы),
  ТОЛЬКО transform (никогда opacity:0 — инвариант сайта: контент всегда виден без JS).
- Поиск в шапке: pill 999px, иконка-лупа слева, ширина 240px.
- Сцены уважают VI-режимы (полный захват всех слоёв во всех 3 схемах), prefers-reduced-motion
  и печать (белые страницы, весь текст).
