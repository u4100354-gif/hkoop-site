## 11. Критика нового дизайна, сравнение со старым (14.10.2026)

Оценка «со стороны»: новый дизайн (Apple-сцены, тёмные/светлые плоскости, крупная типографика)
лучше старого (типовой светлый шаблон: фото-баннер, сетки карточек, заголовки с полоской). Возвращаться
на старый нет смысла. Записано честно, включая слабые места нового.

Сильнее в новом:
1. Иерархия: один экран — одна мысль, крупный заголовок, чипы-факты, CTA внизу сцены; кружки-навигатор.
2. Документы на главной: ровные 4 в ряд, строка «тип · год» прижата к низу (одна высота во всех карточках); сетка сцены 1120px.
3. Блок чисел: центрированный ряд плиток под ЛЮБОЕ количество (4/5/6), flex + wrap; сцена 1020px (act-inner-nums).
4. Мобильная версия вылизана по ритмам отступов; в старой сетки разъезжались.
5. Форма консультации отдельной сценой с акцентом на телефон — правильнее для главной задачи сайта.
6. Внушает доверие внешнему посетителю, не выглядит «самодельным».

Слабее в новом (честно):
1. Скорость: слайдер грузит 5 фоновых фото ≈ 700–900 КБ до первого клика; старый баннер — одна картинка. Районы со слабым 3G страдают.
2. Плотность: старая главная была информативнее (13 партнёров против 6, цифры с сносками сразу). Новая — «более пустые» сцены.
3. Всё по центру: аудитория 35–70+, центр-выровненные тексты сканируются хуже левого выравнивания старого.
4. Слайдер — ручной контент в коде (components/Slider.tsx из 5 слайдов); старый баннер менялся одной картинкой. Поддержка дороже.
