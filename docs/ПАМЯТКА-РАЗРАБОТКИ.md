## 1. Контекст (из файла «Анализ сайта ХКООП.docx» с рабочего стола)
- Текущий сайт: Joomla 3.10.11 (релиз 2022, поддержка кончилась в 2023) + K2 2.10.3 (автор забросил) + собственный шаблон от «Редлайн» (чёрный ящик без исходников).
- Сервер: nginx + HTTPS + HSTS, в целом ок, но служебные файлы светят структуру.
- Вывод записки: живой, но риск взлома растёт, обновления безопасности не выходят. Решение — стратегическое: оставить / обновить / новый.
- Для передачи нужны: хостинг, БД, админка, исходники от Редлайн, бэкап, письменное закрепление. Пока: есть только админка Joomla, БД нет, бэкапов нет. Поэтому делаем НОВЫЙ локально.

## 3. Стек фазы-1 (локально)
- Next.js 14 (App Router) + React + TypeScript + CSS-модули (без Tailwind чтобы пресс-службе и тебе было проще читать).
- Данные: JSON в `/data/*.json`. Никакой БД-сервера не надо.
- Языки: `ru` по умолчанию, структура готова под `en/cn` (папка `dictionaries/` — этап 4).
- Запуск: `npm install` → `npm run dev` → http://localhost:3000
- Старый сайт не трогаем. Деплой только после приёмки.

## 4. Упрощённая структура (предложение)
```
/ (главная: слайдер-планы, новости-4, цифры, документы-быстрые, партнёры)
/news (категории: все-новости, деятельность, профсоюзы)
/docs (фильтр по годам/типам + поиск + PDF-viewer)
/activity (подразделы: правозащита, охрана труда, соцпартнёрство, молодёжка, международное)
/about (союз, история 77 лет, органы, конференция)
/honor (книга почёта — профили)
/partners (плитка 14 ссылок)
/organizations (каталог членских организаций)
/events (календарь-анонсы)
/contacts (карта, форма консультации, горячая линия)
```
Старые URL `/index.php/...` будем редиректить через `redirects` в `next.config.js` на этапе переноса.

## 6. Этапы (перезапускаемые сессии)
- Этап 0 (этот): памятка + каркас + JSON-база + логотип. Готово.
- Этап 1: главная + шапка/подвал + адаптив + слабовидящие + cookie.
- Этап 2: новости + документы (поиск/фильтры) + PDF-просмотр.
- Этап 3: honor + partners + organizations + events + contacts + формы.
- Этап 4: EN/CN словари, умный поиск, Метрика, редиректы, инструкция для пресс-службы.
Каждый этап = отдельная сессия OpenCode. Для рестарта: покажи модели этот файл + `data/*.json`.
