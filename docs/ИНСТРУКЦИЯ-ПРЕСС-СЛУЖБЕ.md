# Инструкция для пресс-службы — как обновлять сайт

Сайт читает данные из базы MariaDB `hkoop` (админка: http://127.0.0.1:8081/, доступы в `db/README.md`).

## Добавить новость

Таблица `news` → Вставить: заполнить `id` (латиницей, без пробелов, например `subbotnik-2026-10`),
`title`, `date` (ГГГГ-ММ-ДД), `category` (одно из: molodezh, ohrana-truda, novosti, mezhdunarodnoe, podderzhka),
`tags` (например `["праздник"]`), `excerpt` (2–3 предложения), `old_url` можно пустым.

## Добавить документ

Таблица `documents`: `id`, `title`, `type` (plan / soglashenie / program / policy), `year`,
положить PDF в `public/docs/` и вписать путь в `file_local` (например `/docs/plan-2027.pdf`).

## Книга почёта / партнёры / события

Аналогично: таблицы `honor` (фото класть в `public/images/honor/`), `partners`, `events`.

## Контакты

Таблица `site_settings`: ключи org, address, phone, fax, email, hours, social_vk, social_tg, social_max.

## Важно

- Даты — формат ГГГГ-ММ-ДД, иначе запись не сохранится.
- После правок страница обновляется сама, ничего перезапускать не надо.
- Резервная копия БД перед массовыми правками: `mysqldump -u hkoop -p hkoop > backup.sql` (пароль спросит, в командной строке не писать — иначе утекёт в history).
