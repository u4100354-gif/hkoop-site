# Инструкция пресс-службе — как обновлять сайт

Новости и документы редактируются через локальную админку — SQL и правки кода для обычной публикации не нужны.

## Запуск

1. Запустить сайт: `npm run dev -- -p 3100` → http://localhost:3100.
2. В другом окне терминала запустить админку: `npm run admin` → http://127.0.0.1:3101.
3. Войти паролем `ADMIN_PASS` из `.env.local`. Не отправлять пароль в чат и не сохранять его в git.

Админка слушает только loopback-адрес компьютера; её API требует активную сессию. Для локальной разработки обе команды должны работать одновременно.

## Новость

1. Открыть **Новости → Новая новость** или нажать «Править» у существующей.
2. Заполнить заголовок, дату, рубрику и краткое описание. При необходимости выбрать картинку из библиотеки или загрузить JPG/PNG/GIF/WebP (до 5 МБ; SVG не принимаются).
3. Добавить текст кнопками форматирования. Нажать **Предпросмотр** и проверить его.
4. Нажать **Сохранить**. Материал сразу записывается в БД и появится на сайте после обновления страницы.

Перед правкой большого текста скопировать исходный текст в черновик вне админки. Удаление новости требует подтверждения, но резервной копии не создаёт.

## Документ

1. Открыть **Документы → Новый документ**.
2. Указать название, тип и год.
3. Загрузить PDF (до 15 МБ) или выбрать файл сайта из списка. Перед сохранением проверить предпросмотр первого листа.
4. Нажать **Сохранить** — запись каталога обновится. Удаление записи документа не удаляет PDF с диска.

Разрешены PDF из `/docs` и внешние ссылки `http(s)`. Проверьте название и файл перед сохранением.

## Членские организации

Раздел **Членские организации** позволяет добавлять, править и удалять карточки: тип, название, территорию, сферу, председателя, телефон, email и адрес. Вносить только подтверждённые и актуальные сведения. Каталог на сайте фильтруется по району/муниципалитету и сфере.

Однократно до первого заполнения владелец БД должен применить миграцию из корня репозитория: `/opt/homebrew/opt/mariadb/bin/mariadb -u root -p hkoop < db/add_organizations.sql` (пароль вводится в интерактивном запросе). Локальный пользователь `hkoop` таких прав не имеет. Не вставляйте в каталог контакты без подтверждения.

## Важное о публикации и безопасности

- Сохранение новости, документа или организации — немедленная публикация в локальную БД, не черновик. Перед нажатием «Сохранить» проверьте превью/поля.
- Общий сайт меняется только отдельной командой «обнови сайт»; локальная админка не публикуется в GitHub Pages.
- Текст новости на сервере пропускается через ограниченный HTML-набор; внешние ссылки допускаются только `http(s)`.
- Секреты — только в `.env.local`. Не публиковать персональные данные без разрешения.
- Перед массовыми изменениями сделать резервную копию БД: `mysqldump -u hkoop -p hkoop > backup.sql` (пароль вводить только в интерактивном запросе).
- При проблеме сохранения проверить, что MariaDB запущена и `npm run admin` всё ещё работает. После 12 часов бездействия войти заново.
