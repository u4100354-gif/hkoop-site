# AGENTS.md — правила работы над сайтом ХКООП

Проект: новый сайт ХКООП (Next.js + App Router + MariaDB). Старый habprof.ru не трогаем.

## Как мы работаем (вайб-кодинг)

**Промпт = ограничения, а не вкус.** «Сделай красиво» ничего не значит. Задаём: стиль, шрифты, палитру, радиусы, плотность сетки, что запрещено.

**3 референса с ролями.** Отсюда — типографика, отсюда — сетка, отсюда — детали. Смешиваем принципы, не копируем сайт целиком.

**Сначала design tokens, потом экраны.** Цвета, типографика, отступы, радиусы, тени — в `:root` (app/globals.css). Не собираем страницы, пока не готова система.

**Стоп-лист (не использовать никогда):**
- фиолетовые градиенты
- glass-карточки (полупрозрачное стекло)
- огромные скругления
- эмодзи вместо иконок (только SVG)
- пустой hero на пол-экрана

**Проси скрин, а не «готово».** После правок — показывать результат (локально + скрин), проверять 390 / 768 / 1440 px.

**Не выдумывать данные.** Цифры, имена, факты — только из БД/старых файлов. Нет данных — оставить прочерк и спросить.

**Не ломать рабочий результат.** Перед перезаписью — проверить, что там уже есть. Не откатывать чужие правки вслепую.

## UI-правила

- **Меньше контейнеров.** Если карточка не нужна — убрать. Не «всё в рамках».
- **Отступы — 3 уровня:** 8 / 24 / 64–96 px. Не всё по 16.
- **Тексты:** действие + результат + цифра. Без «мы — команда профессионалов».
- **Мобилка:** проверить 390 / 768 / 1440. ГЛАВНЫЙ CTA виден и нажимается без зума.
- **Состояния:** у каждого действия — loading / empty / error / success.
- **Доступность:** контраст, фокус-видимый, alt у картинок, версия для слабовидящих (ГОСТ Р 52872).

## Процесс

- Правки — сначала локально (http://localhost:3100), на GitHub Pages только по команде «обнови сайт».
- Перед сборкой и деплоем: `npx tsc --noEmit`.
- Экспорт для Pages пишется в `.next-export` (не трогает dev `.next`), деплой: `bash /tmp/deploy.sh`.
- Секреты — только в `.env.local` (в .gitignore). Пароли/доступы в git не коммитить.
